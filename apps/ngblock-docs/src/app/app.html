Install and use ngblock

Import standalone components directly into your Angular application. The theme is optional and can be customized with CSS variables.

01

Install

npm install ngblock

Use the package from any Angular standalone component.

02

Add the optional theme

"styles": [
  "node_modules/ngblock/styles.css",
  "src/styles.css"
]

Override --ngb-* tokens after the stylesheet import.
